# 🛡️ CyberTechVision
### Building a Safer Digital Future

CyberTechVision is a beginner-friendly cybersecurity education and awareness platform designed to help users understand digital security, learn cybersecurity fundamentals, and explore basic security tools.

The project combines cybersecurity awareness, educational resources, and practical demonstrations in a single web-based platform.

## 🚀 Features

- **User Authentication:** User registration and login system.
- **Security Dashboard:** Personalized dashboard to track user activities.
- **Cybersecurity Tools:** Interactive security tools with demo scan results.
- **Cyber Academy:** Learn cybersecurity concepts and fundamentals.
- **Scan History:** Store and view previous scan results.
- **SQLite Database:** Store user information and scan records.
- **Responsive Design:** User-friendly interface for different screen sizes.

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd CyberTechVision
```

### 3. Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Browser

```text
http://127.0.0.1:5000
```

Register an account, log in, and explore the CyberTechVision platform.

## ⚠️ Important Disclaimer

The current security scan feature generates demonstration results and stores them in the SQLite database. It does not perform actual vulnerability scanning or test external systems.

This project is developed for educational purposes, cybersecurity awareness, and learning.

## 🎯 Project Objective

The main objective of CyberTechVision is to make cybersecurity education more accessible and interactive by bringing learning resources and basic security demonstrations together in one platform.
